# Olá, eu sou Abel Alves 👋

Desenvolvedor de Software **Full Stack** natural do interior da Bahia e formado em Análise e Desenvolvimento de Sistemas pelo **IFBA**. Atuo na construção de sistemas escaláveis, APIs de alta performance e produtos digitais, unindo arquitetura sólida e fluxos de engenharia potencializados por Inteligência Artificial.

Atualmente, também lidero o **Abel Alves Studio**, meu ecossistema independente voltado para desenvolvimento de software, infoprodutos e conteúdo técnico.

---

### 🧠 Minha Filosofia de Engenharia

Assim como em uma boa partida de futebol americano (NFL) — esporte que acompanho de perto —, acredito que desenvolver software vai muito além da "força bruta": é um jogo de **estratégia, leitura de cenário, padrões de projeto (*design patterns*) e precisão na tomada de decisões**.

* **Backend Sólido (desde 2022):** Experiência consolidada na modelagem de dados, regras de negócio e arquitetura de APIs REST e GraphQL.
* **Visão Full Stack & IA (2026+):** Integração completa com o ecossistema React e uso avançado de ferramentas de IA (como Codex, Claude Code e Gemini) como aceleradores reais para escrita, refatoração e revisão de código.
